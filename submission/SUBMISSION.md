## Anything we should know

The agent uses one model call to convert a natural-language question into a restricted
structured plan. Python validates that plan and performs deterministic, read-only
calculations over the Parquet dataset. This keeps numerical answers and source
attribution grounded in the filings rather than generated by the model.

I developed locally with Ollama and `llama3.2:3b`; the grading environment uses the
provided Gemma endpoint through the unchanged frozen `agents/llm.py` interface. The local
Ollama server did not enforce guided JSON, so I added explicit JSON prompting and
semantic validation while retaining the structured-output schema used by the grading
server.

Given more time, I would add broader unit tests, improve issuer resolution beyond
normalized substring matching, and test against a local Gemma-family model closer to the
grading model. I completed the five core chapters and did not attempt the optional bonus
challenges.
